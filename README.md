# Team Cyber Kavach

## Overview
Cyber Kavach is a web application that helps users stay safe online. It was built over three sprints, and this final submission includes all major features, fully implemented and deployed.

## Live Demo
https://ai.studio/apps/a54ac83b-5645-4455-a0d9-b47f4c1226e4

## Problem Statement
Many people fall victim to online threats such as phishing, scams and unsafe links because they lack simple tools and awareness. Cyber Kavach gives users an easy, AI-assisted way to understand and avoid these risks.

## Key Features
- AI-powered analysis that gives clear, real-time guidance
- Simple, intuitive and responsive interface for desktop and mobile
- Easy-to-understand results and safety recommendations
- Input validation and error handling for stable performance

## Tech Stack
- Frontend: React, HTML, CSS, JavaScript
- AI: Google Gemini API via Google AI Studio
- Deployment: Google AI Studio
- Version control: Git and GitHub

## How It Works
1. Open the live link.
2. Enter your input or choose an option.
3. The app processes it with the AI model.
4. Results and advice appear on screen.

## Run Locally
1. git clone https://github.com/2025cser70-max/CyberKavach
2. cd CyberKavach
3. npm install
4. Add GEMINI_API_KEY to a .env file
5. npm run dev
